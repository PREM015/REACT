# Bundle Analysis

## Tools
- webpack-bundle-analyzer
- source-map-explorer
- Vite's built-in rollup visualizer

## Usage (Vite)
```bash
npm install --save-dev rollup-plugin-visualizer
```

## vite.config.js
```js
import { visualizer } from 'rollup-plugin-visualizer';

export default {
  plugins: [
    visualizer({
      open: true,
      gzipSize: true,
      brotliSize: true,
    })
  ]
}
```
