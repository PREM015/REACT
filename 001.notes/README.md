# React Learning Path
## Complete React Development Guide

### Overview
This repository contains a comprehensive, structured approach to learning React from fundamentals to advanced topics.

### Prerequisites
- JavaScript (ES6+)
- HTML/CSS basics
- Node.js & npm installed

### How to Use This Repository
1. Follow the numbered folders sequentially (00 → 21)
2. Read README.md in each section before code examples
3. Complete exercises in the `exercises/` folder
4. Refer to `cheatsheets/` for quick reference

### Learning Path
- **Weeks 1-2**: Folders 00-01 (Setup & Basics)
- **Weeks 3-4**: Folders 02-03 (Patterns & Hooks)
- **Weeks 5-6**: Folders 04-06 (State, Routing, Forms)
- **Weeks 7+**: Advanced topics (07-21)
